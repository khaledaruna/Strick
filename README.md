# STRICT - Responsive Landing Page

**STRICT** is a clean, minimal, and fully responsive one-page website template designed for modern web presentations, agency portfolios, and personal showcases. Built with HTML5, custom CSS3, Bootstrap 5, and FontAwesome icons.

---

##  Features

- **Clean & Minimal Design:** Simple, elegant layout focused on readability and high-impact visual appeal.
- **Fully Responsive:** Adapts seamlessly across desktops, tablets, and mobile devices using Bootstrap 5 grid utilities.
- **Hero Banner:** Full-width hero banner section with custom call-to-action styling.
- **Service Highlights:** Custom icon cards with linear gradient accents.
- **Interactive Portfolio:** Image showcase grid with smooth hover overlay animations.
- **Contact Form Section:** Full-width contact layout featuring a newsletter subscription check and custom form fields.
- **Custom Fonts & Icons:** Integrated Google Fonts (*Lato* & *Oswald*) and Font Awesome icons.

---

##  Built With

- **HTML5** - Semantic layout structure
- **CSS3** - Custom styles, layout flexbox, animations, and typography
- **Bootstrap 5** - Responsive layout framework
- **FontAwesome** - Icon library
